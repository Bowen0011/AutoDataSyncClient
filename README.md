# 🏭 产线测试数据自动汇总系统 (Auto Data Sync Client)

本系统专为制造企业生产线测试机台开发，旨在实现测试数据（如音频 Log、环境监测 CSV、报错日志等）向内网服务器的**全自动、无人值守、增量式**备份与汇总。彻底告别依靠操作工手动 U 盘拷贝或手工复制粘贴的低效模式。

## ✨ 核心特性 (Core Features)

- 🚀 **当日精准增量提取**：独创的时间戳过滤算法，无论本地积压了多少年的历史数据，系统每天仅提取“当日新产生/修改”的文件，极大节省内网带宽。
- 📂 **高容量路径池管理**：支持在一台机台上同时添加并监控数十个不同的本地源路径，一次配置，全部同步。
- 👻 **无感静默挂机防呆**：点击开始或关闭窗口后，程序自动隐藏至右下角系统托盘。防误触、防误关，不干扰产线人员正常测试。
- 🗂️ **全自动层级归档**：在服务器端自动按 `日期 > 线别 > 站别 > 机台编号` 生成严密的文件夹层级，方便生管与 QA 部门事后精准追溯。
- 💾 **配置断电记忆**：所有机台身份与路径池数据自动固化在本地 `config.ini` 中，软件重启或电脑断电开机后配置不丢失。

## 🛠️ 技术栈 (Tech Stack)

- **核心语言**: Python 3.x
- **GUI 框架**: `tkinter` (Python 原生，轻量无依赖)
- **托盘支持**: `pystray` + `Pillow` (用于右下角托盘挂机与交互)
- **打包工具**: `PyInstaller` (封装为单文件绿化版 `.exe`)
