# 🏭 产线测试数据自动汇总系统 v10.1 (Auto Data Sync Client)

本系统专为制造企业生产线测试机台开发，实现测试数据（音频 Log、环境监测 CSV、报错日志等）向内网服务器的**全自动、无人值守、增量式**备份与汇总。彻底告别操作工手动 U 盘拷贝或手工复制粘贴的低效模式。

## ✨ 核心特性

- 🚀 **递归增量同步**：穿透所有子文件夹，仅提取当日修改的文件，对比文件大小智能覆盖
- 🔄 **网络重试**：服务器临时断连自动重试 3 次，产线网络波动不丢数据
- 🛡️ **单文件容错**：个别文件读取失败不中断整体任务，日志标注异常项
- 📂 **路径池管理**：支持一台机台同时监控数十个不同本地源路径
- 👻 **静默托盘挂机**：点击开始或关闭窗口后自动隐藏至系统托盘，防误触防误关
- 🗂️ **自动层级归档**：服务器端按 `日期 > 线别 > 站别 > 机台编号` 生成文件夹层级
- 💾 **配置断电记忆**：所有配置固化在 `config.ini`，重启不丢失
- ⏱️ **宽窗口触发**：定时器±1分钟窗口防踩空，接近目标时间自动缩短轮询间隔
- 📝 **日志行数限制**：自动保留最近 500 行，防止内存膨胀

## 📦 部署与打包

产线机台**无需**安装 Python 环境，打包为单文件 .exe 即可。

### 1. 安装依赖
```bash
pip install pystray Pillow pyinstaller
```

### 2. 打包
```bash
pyinstaller --onefile --windowed --name "DataSyncClient" TestLogSyncClient.py
```

### 3. 部署
将 `dist/DataSyncClient.exe` 拷贝到机台，双击运行，配置路径后点"开始后台自动运行"即可。

## 📁 使用流程

1. 填写机台信息（线别/站别/编号）
2. 设置每日触发时间（如 16:30 下班前自动同步）
3. 添加源路径 → 目的路径映射到路径池
4. 点击「开始后台自动运行」
5. 窗口自动缩至托盘，每日定时静默同步

## 🆕 v10.2 — Trigger 远程触发支持

配合 [LineDataMaster](https://github.com/Bowen0011/LineDataMaster) 主控面板使用：

1. 启动后自动监控服务器 `trigger/line_{线别}/{站别}_cmd.json`
2. 检测到触发指令 → 立即执行同步
3. 完成后写 `_done.json` 标记，主控面板感知后自动触发分析

### Trigger 格式

```json
{
  "action": "sync_now",
  "line": "A03",
  "station_type": "AT",
  "target_root": "//server/data",
  "source_paths": [
    {"src": "D:/TestLog/AT01/TC661", "dst_sub": "AT01"}
  ]
}
```
